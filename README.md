## ShopBack 優惠碼到底是什麼？跟邀請碼、推薦碼有什麼差別

很多人搜「ShopBack 優惠碼」時，其實想找的是一串能在結帳時輸入、立即打折的促銷代碼。但 ShopBack 的運作邏輯不太一樣：它的「優惠碼」本質上是**邀請碼／推薦碼（Referral Code）**，是新用戶註冊時輸入用的，不是結帳時輸入。

## 常見問題快答

**Q1：ShopBack 優惠碼跟結帳時的促銷碼一樣嗎？**
不一樣。ShopBack 的「優惠碼」通常指註冊時輸入的推薦碼／邀請碼，用來解鎖迎新獎賞；結帳時的促銷碼則是各商戶官網自己的折扣碼，跟 ShopBack 無關，但兩者可以同時使用。

**Q2：用推薦連結註冊，跟手動輸入推薦碼有差嗎？**
功能相同，但用推薦連結註冊更省事，系統會自動帶入推薦資訊，避免拼寫錯誤。👉 [點此使用 ShopBack 推薦連結](https://bit.ly/ShopbacK) 是最穩妥的做法。

**Q3：回贍為什麼要等那麼久才確認？**
因為商戶需要等待退換貨期過後，才能確認訂單最終有效。旅遊類訂單還要等入住或航班完成後才會確認，這也是為什麼 OTA 回贍期最長。

**Q4：ShopBack Plus 值得訂嗎？**
如果你每月穩定在 ShopBack 合作商戶消費超過等值 S$400（或對應地區貨幣），Plus 月費的 +0.5% 加乘就能回本。大額採購或旅遊月份訂一個月 Plus、用完即取消，也是常見玩法。

**Q5：超過一年沒用 ShopBack，回贍會歸零嗎？**
會。系統會在到期前兩個月寄 email 提醒，但保險做法是每隔幾個月透過 ShopBack 跳轉下一筆小額訂單（例如foodpanda 叫餐），就能持續刷新活躍紀錄。
